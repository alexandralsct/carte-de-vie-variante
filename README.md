# Carte de vie, variante « style LIFE »

Même application que la carte de vie, avec l'apparence de LIFE (couleurs, formes, menu •••).
Le dépôt ne contient que le code. Les données restent sur l'appareil et se synchronisent avec la clé de synchro saisie une fois dans Réglages → Synchronisation.

Ce dépôt est public (GitHub Pages). Aucune donnée personnelle, aucun secret.
